# GTA 6 Notifier 3.0.1 — extensão Chrome

Esta pasta contém a extensão Chromium pronta para carregar no Google Chrome (e navegadores compatíveis).

## Instalação
1. Abra `chrome://extensions`.
2. Ative o **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação**.
4. Selecione esta pasta (`GTA-6-Notifier-v3.0.1`).

O `manifest.json` desta pasta é o manifesto Chromium da versão 3.0.1.
A pasta `pwa/` mantém os arquivos da PWA incluídos no pacote de versão.
