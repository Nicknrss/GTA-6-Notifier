# Repository structure | Estrutura do repositório

- `extension/chromium/` — Chrome, Brave, and Chromium extension. / Extensão para Chrome, Brave e Chromium.
- `extension/firefox/` — Firefox extension. / Extensão para Firefox.
- `pwa/` — installable Progressive Web App. / Progressive Web App instalável.
- `scripts/monitor.py` — central GitHub Releases and PortWatch collector. / Coletor central de Releases do GitHub e PortWatch.
- `.github/workflows/` — GitHub Actions automation. / Automação do GitHub Actions.
- `data/` — public JSON datasets for events, releases, progress, and leaderboard. / Dados JSON públicos de eventos, releases, progresso e ranking.
- `cloudflare/push-worker/` — optional Web Push delivery service. / Serviço opcional de entrega Web Push.
- `assets/` — project artwork and logo. / Artes e logotipo do projeto.

The project artwork is preserved in `assets/GN-logo.png`. Browser extension and PWA assets use the supplied project branding.

A arte do projeto é preservada em `assets/GN-logo.png`. Os recursos da extensão e da PWA usam a identidade visual fornecida para o projeto.

**Version / Versão: 1.0.0**
